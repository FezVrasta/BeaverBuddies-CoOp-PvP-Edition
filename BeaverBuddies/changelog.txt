v1.1.0-1.3.0
* New: mods' game rules are picked when you create a game, under Customize, and saved with it. Your picks are remembered for the next game.
* Customize opens in a dialog of its own, and nothing on the page changes until you press OK.
* The Load Game screen shows a save's multiplayer mode and the game settings that aren't their defaults.
* Quick match settles game settings along with the difficulty, and open matches list the host's.
* Allow Dev Tools in Co-op is a game setting now, picked when the game is created.
* The desync dialog saves the trace next to Player.log for a report on our Discord. The automatic report upload, which never worked in this edition, is gone.
* Load Game from the main menu no longer offers to host, the Multiplayer menu's buttons have tooltips, and the New Game summary names the multiplayer mode.
* Fixed the Customize list's fields being cut off when hosting or finding a match.

v1.1.0-1.2.0
* New: find a match with anyone through Steam, from Find a match in the main menu.
* New: a list of open matches to join, and inviting friends without the Steam overlay.
* New: pick a multiplayer mode when hosting or finding a match. Mods can add their own.
* Players' factions are checked as they join, and mods can place each player's start.
* Fixed desyncs from instant build and from refused placements. Clients keep closer to the host.
* Rehosting a saved game uses the same port.

v1.1.0-1.1.0
* This is BeaverBuddies Co-Op/PvP Edition, my fork of BeaverBuddies. It replaces the original mod (same mod id), so everyone in a game needs this version.
* New: see where the other players are pointing. Turn it off with "Show Player Cursors" in the mod settings.
* New: dev tools work in co-op and what you do with them is synced. The host can turn them off for everyone with "Allow Dev Tools in Co-op".
* Faster simulation in big settlements, from the optimizations of T3MP (More More More Performance!) by toropippi.
* Fixed a desync in water source strength.
* Fixed a crash when quitting the game on Windows.
* Demolition sounds fade out far from the camera.
* For modders: other mods can sync their own actions and decide where each player may build, which is what PvP mods build on. See Doc/Modding.md.

* New Setting: "Reduce the number of forced pauses" stops the game from auto-pausing when deconstructing/researching, or optionally when opening the menu. Change settings with Mods->BeaverBuddies (settings button). Credit: @SamuZad

  * Power Clutch settings. Credit: @JoeStead
